100 Days of Code — DSA in C

A 100-day problem-solving challenge focused on building strong fundamentals in Data Structures and Algorithms through consistent coding practice.

The goal is to solve one problem per day, document the approach and complexity, and maintain a consistent GitHub contribution history. The challenge covers arrays, hashing, strings, linked lists, stacks, queues, binary search, trees, heaps, backtracking, graphs, dynamic programming, greedy algorithms, and bit manipulation.

Daily Workflow

For each problem:

1. Understand the problem.
2. Identify the appropriate algorithm or data structure.
3. Implement the solution in C.
4. Test with different inputs.
5. Analyze time and space complexity.
6. Document the approach and learning.
7. Commit the solution to GitHub.

The challenge recommends roughly one problem per day, while allowing difficult problems to take longer when necessary.

Goal

Complete all 100 days with consistent problem solving, clean C implementations, meaningful documentation, and a visible GitHub contribution history.
